17장 이뇨제 2종(Hydrochlorothiazide · Furosemide). 앞 두 단계(chlorosulfonation → NH₄OH)가 같고 마지막 단계만 갈린다. 가릴 항목을 고르고, 가려진 칸을 눌러 답을 확인하세요. 다시 누르면 또 가려집니다. 구조 그림은 모두 교재 스킴에서 가져왔어요.

Hydrochlorothiazide 하이드로클로로티아자이드
Thiazide계 이뇨제 (Novartis, 1959) · 17장 p.261–262 · 그림: 교재 스킴
6-Chloro-3,4-dihydro-2H-1,2,4-benzothiadiazine-7-sulfonamide 1,1-dioxide

m-클로로아닐린에 chlorosulfonation으로 SO₂Cl 두 개 → NH₄OH로 설폰아마이드 두 개 → HCHO 하나로 두 N을 CH₂로 묶어 고리를 닫는다. 3단계.

한눈에 보는 핵심반응
단계핵심반응무엇이 바뀌나
1Chlorosulfonation (EAS ×2)Ar–H ×2 → Ar–SO₂Cl ×2
2Sulfonamide 형성SO₂Cl → SO₂NH₂ ×2
3HCHO 고리화 (N–CH₂–N)NH₂ + SO₂NH₂ → 6원 고리

Chlorosulfonation (EAS) · NH₂(o/p 지향)가 가리키는 두 자리에 SO₃H가 먼저 들어가고, HOSO₂Cl이 한 번 더 반응해 arylsulfonic anhydride → ArSO₂Cl. 그래서 HOSO₂Cl은 과량.

2
NH₄OH, 100 °C, 1 h
Sulfonamide formation
4-Amino-6-chloro-1,3-benzenedisulfonamide3

설폰아마이드 형성 · NH₃가 S를 공격하고 Cl⁻가 빠진다 (아실 치환과 같은 부가–제거). SO₂Cl 두 개가 모두 SO₂NH₂.

3
HCHO, 20% HCl/EtOAc, 90 °C, 1 h
Cyclocondensation (HCHO)
Hydrochlorothiazide4

고리화 축합 · 아닐린 NH₂ + HCHO → 이미늄 → 옆 SO₂NH₂의 N이 분자내 공격 → N–CH₂–N 6원 고리 (3,4-dihydro). HCHO 탄소 = 고리 C3.

시험 포인트
  • Chlorosulfonation: ArSO₃H → (HOSO₂Cl 한 번 더) arylsulfonic anhydride → ArSO₂Cl
  • NH₂가 o/p 지향 → 두 자리에 SO₂Cl
  • HCHO 한 분자 = 고리의 CH₂ (aminal)
  • 이름: benzothiadiazine 1,1-dioxide = 벤젠 + S·N·N 6원 고리, S에 O 두 개
앞에서 나온 같은 반응
  • HOSO₂Cl → 설폰아마이드: 중간 7주차 Sildenafil · Vardenafil
  • HCHO + 아민 → 이미늄: 중간 1주차 Zolpidem Mannich
Furosemide 푸로세마이드
고효능(loop) 이뇨제 (Sanofi-Aventis, 1966) · 17장 p.263 · 그림: 교재 스킴
4-Chloro-N-furfuryl-5-sulfamoylanthranilic acid

HCTZ와 앞 두 단계(chlorosulfonation → NH₄OH)가 똑같다. 마지막에 SNAr로 furfurylamine이 COOH 옆 Cl을 밀어낸다.

한눈에 보는 핵심반응
단계핵심반응무엇이 바뀌나
1Chlorosulfonation (EAS)Ar–H → Ar–SO₂Cl
2Sulfonamide 형성SO₂Cl → SO₂NH₂
3SNArAr–Cl → Ar–NH–CH₂(furyl)

SNAr (NAS) · 전자를 끄는 COOH·SO₂NH₂가 고리를 활성화 → 아민이 C–Cl에 부가(Meisenheimer) → Cl⁻ 이탈. COOH 옆 Cl이 치환돼 anthranilic acid 골격.

시험 포인트
  • HCTZ와 1·2단계 동일, 3단계만 SNAr
  • SNAr 조건: EWG(COOH, SO₂NH₂)가 이탈기 o/p에
  • 이름 anthranilic acid = 2-아미노벤조산 → SNAr로 생긴 N이 COOH 옆
앞에서 나온 같은 반응
  • SNAr: 중간 2주차 Olanzapine · 6주차 Terazosin · 7주차 Quetiapine
  • Chlorosulfonation: 17장 Hydrochlorothiazide
